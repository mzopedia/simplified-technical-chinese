# 日志采集器部署指南

本文档主要是介绍一下如何在生产环境对日志采集器进行部署以及相关配置的说明，适用于运维同学以及对此感兴趣的开发同学等。

## 部署前的准备

首先需要确认服务器的操作系统版本是比较新的，然后检查一下磁盘空间是否充足（一般来说 10GB 以上就基本够用了），最后还要保证服务器能够访问到我们的镜像仓库。如果服务器无法访问外网的话，需要联系网络组的同事开通相关的权限，这个过程可能需要几天时间，所以最好尽快提交申请。

## 部署步骤

1. 用户首先需要登陆到目标服务器，然后切换到 /opt 目录并且创建一个用于存放采集器配置文件以及运行时产生的临时数据的工作目录。
2. 请下载安装包并进行解压，注意安装包必须和服务器的 CPU 架构匹配，否则会报错。
3. 修改配置文件里的 server_addr（服务端地址）参数，把它改成实际的地址，然后再修改一下 batch_size 参数，这个参数不要设置得太大也不要设置得太小，一般几百左右就可以了。
4. 执行启动命令以后，采集器会被 systemd 接管，日志会由采集器定期上报到服务端，这时候应该能看到状态变成 active 了吧？
5. 开启调试功能（如果需要排查问题的话）。

## 常见问题

如果采集器起不来，大概率是因为配置文件的格式有问题，可以用校验命令对配置文件进行校验，校验通过之后再重新拉起服务。采集器的内存占用一般在 200MB 左右，如果内存占用非常高，说明 batch_size 参数设置得不合适，适当调小即可。近期我们会发布新版本来对这个问题加以优化，届时性能会提升 3 倍以上，内存占用也会降低 2 倍。
